# 動作確認の簡易化

ルートディレクトリで、フロントエンドサーバー・バックエンドサーバー・DBコンテナを1つのコマンドで起動したい

## `concurrently`

```json:package.json
{
  "name": "rota-tracker",
  "private": true,
  "description": "リポジトリ全体の開発ツール置き場",
  "scripts": {
    "dev": "npm run db:up && concurrently -k -n api,web -c magenta,cyan \"npm:dev:api\" \"npm:dev:web\"",
    "dev:api": "dotnet run --project api/WheelTracker.Api",
    "dev:web": "npm run dev --prefix web",
    "db:up": "docker compose --env-file db/.env -f db/docker-compose.yaml up -d --wait",
    "db:down": "docker compose --env-file db/.env -f db/docker-compose.yaml down",
    "db:logs": "docker compose --env-file db/.env -f db/docker-compose.yaml logs -f"
  },
  "devDependencies": {
    "concurrently": "^10.0.5",
    "lefthook": "^2.1.12"
  },
  "engines": {
    "node": ">=24",
    "npm": ">=11"
  }
}
```

`"dev": "npm run db:up && concurrently -k -n api,web -c magenta,cyan \"npm:dev:api\" \"npm:dev:web\"`　の詳細

| オプション | 意味 |
| --- | --- |
| `-k` (`--kill-others`) | どちらか一方が終了 / クラッシュしたら、もう片方も道連れで終了させる |
| `-n api,web` | ログの行頭に `[api]` `[web]` のプレフィックス（目印）を付けて見分けやすくする |
| `-c magenta,cyan` | 指定したプレフィックスに色を付ける |
| `npm:dev:api` | `npm run dev:api` を実行するという意味の省略記法 |
