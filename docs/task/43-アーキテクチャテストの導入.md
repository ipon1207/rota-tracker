# アーキテクチャテストの導入

## ArchUnitNET

### 導入

```bash
dotnet add package TngTech.ArchUnitNET.xUnitV3
```

### ルールの設定

- [User Guide](https://archunitnet.readthedocs.io/en/latest/guide/)

#### アーキテクチャの読み込み

テストの実行速度を最適化するために、テスト開始時にアーキテクチャを一度だけ読み込む

```CSharp
// 対象の .csproj に含まれる代表的な型を指定してアセンブリを取得
private static readonly Architecture Architecture = new ArchLoader().LoadAssemblies(
  typeof(ProjectRepository).Assembly,
  typeof(Dapper.SqlMapper).Assembly
).Build();
```

- 対象プロジェクト内の任意の型（クラスやインターフェース）を経由して取得する

#### レイヤーの宣言

テスト全体で使いまわすレイヤーや型グループを変数として扱う

```CSharp
private readonly IObjectProvider<IType> ExampleLayer = 
  Types().That().ResideInAssembly("ExampleAssembly").As("Example Layer");

private readonly IObjectProvider<Class> ExampleClasses =
  Classes().That().ImplementInterface("IExampleInterface").As("Example Classes");

private readonly IObjectProvider<IType> ForbiddenLayer =
  Types().That().ResideInNamespace("ForbiddenNamespace").As("Forbidden Layer");

private readonly IObjectProvider<Interface> ForbiddenInterfaces =
  Interfaces().That().HaveFullNameContaining("forbidden").As("Forbidden Intefaces");
```

- `ExapmleLayer` の定義: `Types().That().ResideInAssembly("ExampleAssembly")`

  `"ExampleAssembly"` アセンブリ内に存在するすべての型（クラス、インターフェース、構造体など）を抽出して1つのレイヤーとしてグループ化

- `ExampleClasses` の定義: `Classes().That().ImplementInterface("IExampleInterface")`

  `"IExampleInterface"` を実装しているクラスのみを絞り込み

- `ForbiddenLayer` の定義: `Types().That().ResideInNamespace("ForbiddenNamespace")`

  `"ForbiddenNamespace"` という名前空間に属するすべての型を抽出

- `ForbiddenInterface` の定義: `Interface().That().HaveFullNameContaining("forbidden")`

  完全修飾名に `"forbidden"` という文字列が含まれているインターフェースを抽出

- `.As("表示名")` メソッドの役割

  定義した各グループに分かりやすい別名を付与している

#### テストケース

`ExampleClasses` が `ExampleLayer` 内に存在することの検証

```CSharp
[Fact]
public void TypesShouldBeinCorrectLayer() {
  IArchRule exampleClassesShouldBeInExampleLayer = 
    Classes().That().Are(ExampleClasses).Should().Be(ExampleLayer);
  IArchRule forbiddenInterfacesShouldBeInForbiddenLayer =
    Interface().That().Are(ForbiddenInterfaces).Should().Be(ForbiddenLayer);

  // 定義したルールをアーキテクチャに対して検証
  exampleClassesShouldBeInExampleLayer.Check(Architecture);
  forbiddenInterfacesShouldBeInForbiddenLayer.Check(Architecture);

  // 複数のルールを結合して検証することも可能
  IArchRule combinedArchRule = 
    exampleClassesShouldBeInExampleLayer
    .And(forbiddenInterfacesShouldBeInForbiddenLayer);

  combinedArchRule.Check(Architecture);
}
```

`ExampleLayer` の型が `ForbiddenLayer` のオブジェクトに依存していないことの検証

```CSharp
[Fact]
public void ExampleLayerShouldNotAccessForbiddenLayer()
{
  // Because() で失敗時に出力される理由を設定可能
  IArchRule exampeLayerShouldNotAccessForbiddenLayer = Types().That()
    .Are(ExampleLayer).Should().NotDependOnAny(ForbiddenLayer)
    .Because("it's forbidden");

  exampleLayerShouldNotAccessForbiddenLayer.Check(Architecture);
}
```

`ForbiddenInterfaces` を実装するクラスの命名規則の検証

```CSharp
[Fact]
public void ForbiddenClassesShouldHaveCorrectName() 
{
  Classes().That().AreAssignableTo(ForbiddenInterfaces)
    .Should().HaveNameContaining("forbidden").Check(Arhitecture);
}
```

`ExampleClasses` が `ForbiddenLayer` または名前に `"forbidden"` を含むメソッドを呼び出していないことの検証

```CSharp
[Fact]
public void ExampleClassesShouldNotCallForbiddenMethods()
{
  Classes().That().Are(ExampleClasses).Should()
    .NotCallAny(MethodMembers().That()
    .AreDeclaredIn(ForbiddenLayer).Or().HaveNameContaining("forbidden"))
    .Check(Architecture)
}
```

#### 検証可能な項目

**名前空間の依存関係ルール**: 例）`Model` 名前空間内の型は `Controller` 名前空間に依存してはならない

```CSharp
IArchRule rule = Types().That().ResideInNamespace("Model").Should()
                    .NotDependOnAny(Types().That().ResideInNamespace("Controller"));
```

#### 設定したいルール

- リポジトリはエンドポイントに依存しない
- `Features` の中で、`Repository` 以外は `Dappper` に依存しない
- 機能同士は依存しない

```CSharp
using ArchUnitNET.Domain;
using ArchUnitNET.Fluent;
using ArchUnitNET.Loader;
using ArchUnitNET.xUnitV3;
using WheelTracker.Api.Features.Projects;
using static ArchUnitNET.Fluent.ArchRuleDefinition;

namespace WheelTracker.Tests;

public class ArchitectureTest
{
    private static readonly Architecture _architecture = new ArchLoader().LoadAssemblies(
        typeof(Project).Assembly,
        typeof(Dapper.SqlMapper).Assembly
    ).Build();

    [Fact]
    public void RepositoryはEndpointsに依存しない()
    {
        IArchRule rule =
            // 【主語】すべての型で
            Classes()
            // 【条件】名前が "Repository" で終わるものは
            .That().HaveNameEndingWith("Repository")
            // 【検証】以下の対象すべてに依存しない
            .Should().NotDependOnAny( 
                //【対象】名前が "Endpoints" で終わる型
                Types().That().HaveNameEndingWith("Endpoints") 
            );

        rule.Check(_architecture);
    }

    [Fact]
    public void Features名前空間内でRepository以外はDapperに依存しない()
    {
        IArchRule rule =
            // 【主語】すべての型で
            Types()
            // 【条件】WheelTracker.Api.Features 配下の名前空間すべての
            .That().ResideInNamespaceMatching(@"WheelTracker\.Api\.Features")
            // 【条件】かつ、名前が Repository で終わるもの
            .And().DoNotHaveNameEndingWith("Repository")
            // 【検証】Dapper 名前空間の任意のものに依存してはならない
            .Should().NotDependOnAny(
                Types().That().ResideInNamespaceMatching(@"Dapper")
            );

        rule.Check(_architecture);
    }

    [Fact]
    public void Features同士は依存しない()
    {
        IArchRule rule = SliceRuleDefinition
            .Slices()
            // (*) の部分は Projects や Customers などに独立した境界を作成する
            .Matching("WheelTracker.Api.Features.(*)")
            // 各境界は互いに他の境界に依存しない
            .Should().NotDependOnEachOther();

        rule.Check(_architecture);
    }
}
```
