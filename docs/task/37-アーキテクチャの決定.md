# アーキテクチャの決定

## 全体的な方針

- AI主軸のコーディングでも人間のコーディングでも複雑にならない設計を目指す
- コード・アーキテクチャ・DB・パッケージ・ライブラリなど様々な変更に優れた設計を目指す
- 初期段階のため、小規模的に設計し、中・大規模の拡張を考慮する

> [!NOTE]
>
> 将来を予測して設計を決めることは難しいため、抽象化で備えるのではなく
>
> - 依存を少なく保つ
> - 依存を一方向に保つ
> - 境界を越えたことに気付ける仕組みを置く
>
> 上記の項目を考慮し、小さく始める
