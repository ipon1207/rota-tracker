## Tailwind CSSの導入方法

- [Get started with Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite)

Tailwind CSSのインストール

```bash
npm install tailwindcss @tailwindcss/vite
```

Viteプラグイン (`web\vite.config.ts`) にTailwind CSSを設定

```ts:vite.config.ts
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
})
```

グローバルCSSファイル (`web\src\index.css`) にTailwind CSSをインポート

```CSS:index.css
@import "tailwindcss";
```

## shadcd/uiの導入方法

※ 前提としてTailwind CSSの導入が必要

- [Install and Configure shadcn/ui for Vite](https://ui.shadcn.com/docs/installation/vite)

`tsconfig.json` に `@/*` をエイリアスに設定

```json:tsconfig.json
{
  "files": [],
  "references": [
    {
      "path": "./tsconfig.app.json"
    },
    {
      "path": "./tsconfig.node.json"
    }
  ],
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

`tsconfig.app.json` にも同様の設定

```json:tsconfig.app.json
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

Viteが `@` エイリアスを解決できるように設定

```bash
npm install -D @types/node
```

```ts:vite.config.ts
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})
```

CLIを起動

```bash
npx shadcn@latest init
```

> ### `npm run dev` 実行時に以下の警告文が出る場合の対処
>
> ```PlainText
> (!) Your Vite config uses features that are unsupported by `configLoader: 'native'`, which is planned to become the default in a future major version of Vite:
> - `__dirname` (vite.config.ts:16:25). Use `import.meta.dirname` instead
> Set `VITE_CONFIG_NATIVE_IGNORE_WARNING=true` to suppress this warning.
> ```
>
> `vite.config.ts` を以下のように変更する
>
> ```ts:vite.config.ts
> import react, { reactCompilerPreset } from '@vitejs/plugin-react';
> import babel from '@rolldown/plugin-babel';
> import { defineConfig } from 'vite';
> import tailwindcss from '@tailwindcss/vite';
> import path from 'path';
> 
> // <https://vite.dev/config/>
> export default defineConfig({
>   plugins: [
>     react(),
>     babel({ presets: [reactCompilerPreset()] }),
>     tailwindcss()
>   ],
>   resolve: {
>     alias: {
>       "@": path.resolve(import.meta.dirname, "./src")
>     }
>   }
> });
> ```

## Oxlintのlint除外対象の指定

- [Ignore files](https://oxc.rs/docs/guide/usage/linter/ignore-files.html)

`.oxlintrc.json` に以下の項目を設定する（`.gitignore` と同様の書き方をする）

```json:.oxlintrc.json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "oxc"],
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }]
  },
  "ignorePatterns": ["src/components/ui/**"]
}
```

## `vite.config.ts` に `test` プロパティがないエラーが出る

`vite.config.ts` に `test` プロパティを追加した際に、VSCodeから以下のエラーが出る

```PlainText
この呼び出しに一致するオーバーロードはありません。
前回のオーバーロードにより、次のエラーが発生しました。
オブジェクト リテラルは既知のプロパティのみ指定できます。'test' は型 'UserConfigExport' に存在しません。

index.d.ts(3366, 25): 前回のオーバーロードはここで宣言されています。
```

`vite` の `defineConfig` にはもともと `test` プロパティは存在しないため、Vitestの型が乗った `defineConfig` に差し替える

```ts:vite.config.ts
import { defineConfig } from 'vitest/config';
```
