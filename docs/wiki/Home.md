# Rota Tracker

単一ファイルの React アプリ「車輪の再発明トラッカー」を、DB・API・フロントエンドの3層構成に作り変えるプロジェクト

目的は完成そのものより、指定した技術スタックを一通り通して学ぶこと

## 何をするアプリか

「車輪の再発明」として取り組む練習プロジェクトの一覧と、その進捗を記録する

- カテゴリ別のプロジェクト一覧と、ステータス（未着手・進行中・完了）の切り替え
- 取り組みの記録（使った言語・リポジトリURL・着手日・完了日・メモ）
- 学習ガイド・用語集・ロードマップの表示
- 全体・カテゴリ別の進捗集計

## 技術スタック

バージョンはリポジトリの `package.json`・`global.json` を参照

| 層 | 技術 |
| --- | --- |
| フロントエンド | React / TypeScript / Vite / React Router / TanStack Query / TanStack Table / Tailwind CSS / shadcn/ui / Base UI / Zod |
| バックエンド | ASP.NET Core / Dapper |
| DB | PostgreSQL |

## このWikiの読み方

| ページ | 内容 |
| --- | --- |
| サイドバーの **task** | 実装したタスクごとの思考ログ（書いた時点の記録。実装と食い違っても直さない） |
| サイドバーの **spike** | 実装前の調査ログ |
| `DESIGN_NOTES` | 不可逆な決定の記録（追記のみ） |

セットアップ手順・規約・アーキテクチャはコードと一緒に管理しているため、[リポジトリ](https://github.com/ipon1207/rota-tracker) を参照
