# アーキテクチャテストの調査

## アーキテクチャテストの概要

- [アーキテクチャテストでレイヤーの依存ルールを守る](https://zenn.dev/balista/articles/14-article-php-architecture-test)

アーキテクチャテストとは、コード依存関係がアーキテクチャのルール通りになっているかを静的解析で検証するテストのこと

例）「Domain層はInfrastrcture層に依存していけない」というルールを**ツールで自動的に検知する仕組み**

### アーキテクチャテストの必要性

- 急ぎの対応により適当に `import` してしまう
- IDEの自動補完により、間違ったクラスを利用してしまう
- 新規参加した開発者がアーキテクチャのルールを把握できない
- レビュアーが都度、レイヤー間の依存関係をチェックできない
- レビュアー自身がアーキテクチャルールを正しく把握していない
- AIが出力するコードに対して、`.md` やプロンプトで必ずしもアーキテクチャを守る保証はない（確率的モデルのため）
