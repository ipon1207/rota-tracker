# ドキュメント生成ライブラリ

## C#のドキュメント自動生成

- [XML API ドキュメントのコメントを生成する](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/xmldoc/)
- [C# ドキュメント コメントとして推奨される XML タグ](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/xmldoc/recommended-tags)

C#のXMLコメント → OpenAPI → openapi-typescriptの経路において、ドキュメントを自動生成する意味がありそう

### バックエンド側

`.csproj` に以下の設定をすることで、OpenAPI生成が、メソッド・クラス・メンバーのXMLドキュメントコメントのメタデータを取り込むようになる

```xml
<PropertyGroup>
  <GenerateDocumentationFile>true</GenerateDocumentationFile>
</PropertyGroup>
```

ビルド時にソースジェネレーターがアセンブリとプロジェクト参照からXMLコメントを収集し、OpenAPIドキュメントトランスフォーマー経由で挿入するコードを生成

- `<summary>`
- `<param>`
- `<returns>`
- `<response>`
- `<example>`
- `<deprecated>`
- `<inheritdoc>`

が対応するタグ

### フロントエンド側

`openapi-typescript` は description を JSDoc として生成物に出力

```bash
npx openapi-typescript ./openapi.json -o ./src/api/schema.d.ts
```

## 他のライブラリ

- TypeDocやdocFxがあるが、生成サイトを別途開く動機があまりない
- 決めた規約により、リッチなドキュメントにはならない

→ 採用は見送り
