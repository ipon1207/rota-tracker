# ミューテーションテスト

- [変異テスト](https://learn.microsoft.com/ja-jp/dotnet/core/testing/mutation-testing)

## ミューテーションテストの概要

単体テストの品質を評価する手法

C#の場合は、Stryker.NET ツールを利用して、コード内を自動的に変更し、テスト実行することで詳細なレポートを生成する

### テストシナリオの例

割引を考慮して価格を計算する `Calculate` メソッドを持つ `PriceCalculator.cs` クラスを考える

```CSharp
public class PriceCalculator
{
    public decimal CalculatorPrice(decimal price, decimal discountPercent)
    {
        if (price <= 0)
        {
            throw new ArgumentException("Price must be greater than zero");
        }

        if (discountPercent < 0 || discount > 100)
        {
            throw new ArgumentException("Discount percent must be between 0 and 100");
        }

        var discount = price * (discount / 100);
        var discountedPrice = price - discount;

        return Math.Round(discountedPrice, 2);
    }
}
```

上記のメソッドは、次の単体テストが存在する

```CSharp
[Fact]
public void ApplyDiscountCorrectly()
{
    decimal price = 100;
    decimal discountPercent = 10;

    var calculator = new PriceCalculator();

    var result = calculator.CalculatePrice(price, discountPercent);

    Assert.Equal(90.00m, result);
}

[Fact]
public void InvalidDiscountPercent_ShoudThrowException()
{
    var calculator = new PriceCalculator();

    Assert.Throws<ArgumentException>(() => calculator.CalculatePrice(100, -1));
    Assert.Throws<ArgumentException>(() => calculator.CalculatePrice(100, 101));
}

[Fact]
public void InvalidPrice_ShouldThrowException()
{
    var calculator = new PriceCalculator();

    Assert.Throws<ArgumentException>(() => calculator.CalculatePrice(-10, 10));
}
```

## ツールのインストール

**Stryker.NET** をインストールする

```bash
dotnet tool install -g dotnet-stryker
```

stryker を実行するには、単体テストプロジェクトが配置されているディレクトリ内から呼び出す

```bash
dotnet stlyker
```
