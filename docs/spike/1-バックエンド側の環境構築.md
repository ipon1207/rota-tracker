# バックエンド側の環境構築

## .NET テンプレート確認方法

```ps
dotnet new list
```

## ASP.NET Core の種類

- ASP.NET Core（空）
- ASP.NET Core Web API
- ASP.NET Core Web API (native AOT)

の3種類からどれを選択すべきか問題

|                  | ASP.NET Core（空）              | Web API                             | Web API (native AOT)                        |
| ---------------- | ------------------------------- | ----------------------------------- | ------------------------------------------- |
| `Program.cs`     | `CreateBuilder` + `MapGet("/")` | サンプルエンドポイント一式          | `CreateSlimBuilder` ベース                  |
| OpenAPI          | なし（自分で追加）              | `Microsoft.AspNetCore.OpenApi` 入り | `Microsoft.AspNetCore.OpenApi` 入り         |
| `.http` ファイル | なし                            | あり                                | あり                                        |
| ビルド           | 通常                            | 通常                                | `PublishAot=true`、ネイティブバイナリを出力 |

今回は Web APIを選択

## テストプロジェクトに別のプロジェクトの参照を追加する

```ps
dotnet add テストプロジェクトのcsproj reference 参照を追加したいcsproj
```

```ps
dotnet add .\WheelTracker.Tests\WheelTracker.Tests.csproj reference .\WheelTracker.Api\WheelTracker.Api.csproj
```

## dotnet CLI で NuGetパッケージを追加

プロジェクトファイル (`.csproj`) があるディレクトリで次のコマンドを実行

```ps
dotnet package add パッケージ名
```

```ps
dotnet package add Dapper
dotnet package add Microsoft.Data.SqlClient
```
